# Ponte para o segundo cérebro

Este repositório é código. O contexto e histórico de decisão vivem no vault do Obsidian, fora daqui. Antes de qualquer tarefa:

1. Leia o mapa completo: `CAMINHO_DO_VAULT/AGENTS.md`
2. Leia o status deste projeto específico: `CAMINHO_DO_VAULT/projects/lodgra.md`
3. Se a tarefa gerar uma decisão relevante (arquitetura, modelo de dados, pivô de estratégia), registre uma linha em `CAMINHO_DO_VAULT/decisions.md` ao final.
4. Se a tarefa revelar um erro ou lição (ex: algo que pareceu certo e não era), registre em `CAMINHO_DO_VAULT/LEARNINGS.md`.

## Substituir antes de usar

Troque `CAMINHO_DO_VAULT` acima pelo caminho absoluto real do vault na sua máquina (ex: `/Users/fabio/second-brain` ou `C:\Users\fabio\second-brain`). Faça essa troca uma vez e não mexe mais.
