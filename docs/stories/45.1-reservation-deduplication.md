# Story 45.1: Reservation Deduplication System

**Epic**: Epic 45 - Reservation Management  
**Status**: COMPLETE  
**Priority**: HIGH  
**Date**: 2026-08-12

## Story

As a property manager, I need to prevent orphaned/duplicate reservations when sync fails and I create them manually, so that when sync resumes, the system can match and merge instead of creating duplicates.

## Acceptance Criteria

- [x] Add UNIQUE constraint to prevent duplicate (organization_id, external_reservation_id, channel_connection_id)
- [x] Display reservation number on detail page
- [x] Display platform/source on detail page  
- [x] Document deduplication strategy
- [x] Ensure manual reservations store correct external_reservation_id

## Technical Implementation

### 1. Database Constraint

Added UNIQUE constraint to `reservations` table:

```sql
ALTER TABLE reservations ADD CONSTRAINT unique_reservation_per_channel 
  UNIQUE (organization_id, external_reservation_id, channel_connection_id);
```

**Purpose**: Guarantees that for each organization and platform, a reservation number can only exist once. Prevents manual + sync from creating duplicates.

### 2. Field Mapping

Existing fields (no migration needed):
- `external_reservation_id` → Stores the actual reservation number from platform
- `channel_connection_id` → FK to channel_connections (booking, airbnb, etc)
- `organization_id` → Tenant isolation

### 3. UI Enhancements

Added **"Informações da Reserva"** card on detail page showing:
- **Número da Reserva**: external_reservation_id (platform number or manual-{timestamp})
- **Plataforma**: channel.channel from channel_connections (BOOKING, AIRBNB, MANUAL)

### 4. Deduplication Flow

```
Scenario: Sync fails, user creates manually

1. Manual Create
   - User enters reservation number: 12345678 (from Booking.com)
   - System stores: external_reservation_id = "12345678"
   - System stores: channel_connection_id = booking_channel_uuid

2. Sync Resumes
   - Sync receives: external_reservation_id = "12345678", channel = booking
   - Queries: SELECT * FROM reservations 
     WHERE organization_id = X 
     AND external_reservation_id = "12345678" 
     AND channel_connection_id = booking_channel_uuid
   
3. Result
   - Found existing → MERGE (update with sync data, don't duplicate)
   - Not found → CREATE (true new reservation from sync)
```

## Benefits

| Benefit | Impact |
|---------|--------|
| **No Orphans** | Sync resume merges with manual, prevents duplicates |

| **Data Integrity** | UNIQUE constraint enforces at DB level |

| **Auditability** | external_reservation_id links back to original platform |
