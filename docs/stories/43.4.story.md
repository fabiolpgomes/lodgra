# Story 43.4: SMS Notifications for Direct Bookings

**Depends On:**
- ✅ Story 43.2 (Direct Booking Creation)
- ✅ Story 43.3 (Email Confirmation)

---

## Story

As an **admin creating a direct booking**, I need to **send an SMS confirmation to the guest** — so they receive an immediate notification with key booking details on their phone.

---

## Acceptance Criteria

- [ ] **SMS Notification Trigger** — Send SMS after successful reservation creation
  - Trigger: POST /api/admin/reservations returns success
  - Send to: Guest phone number (optional field)
  - Content: Key booking details (property, dates, price, confirmation ID)
  - Timing: Immediate (async, non-blocking)
  - Success: SMS queued without delaying API response

- [ ] **SMS Service Integration** — Use Twilio or similar
  - API credentials from environment variables
  - Error handling: Log failures without crashing reservation creation
  - Retry logic: Attempt 2-3 times if initial send fails
  - Rate limiting: Respect SMS provider limits

- [ ] **SMS Content** — Professional, concise message
  - Portuguese language (pt-BR)
  - Include: Property name, check-in date, total price
  - Include: Confirmation/reservation ID
  - Include: Support contact info
  - Max 160 characters or multiple SMS parts

- [ ] **Unit Tests** — SMS service logic
  - Test successful send
  - Test error handling (service down)
  - Test retry logic
  - Test missing phone number (graceful skip)
  - Test message formatting

## Dev Notes

**SMS Provider Options:**
1. **Twilio** (recommended)
   - $0.0075 per SMS (Brazil rate)
   - Reliable, good deliverability
   - Environment variable: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`

2. **AWS SNS** (alternative)
   - Similar pricing, built into AWS infrastructure
   - Environment variables: `AWS_SNS_REGION`, `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`

3. **AWS Pinpoint** (alternative)
   - Better for analytics, higher cost
   - More features than needed

**Recommendation:** Twilio (simplest, no AWS required)

**SMS Message Template:**
```
Olá {guestName}! Sua reserva foi confirmada. {propertyName}, {checkInDate} a {checkOutDate}. Total: {finalPrice}. Confirmação: {reservationId}. Dúvidas? Ligue {supportPhone}.
```

**Error Handling Strategy:**
```
try:
  send_sms()
catch:
  log error to console
  attempt retry (max 2)
  if all attempts fail:
    - return success anyway (don't block reservation)
    - log warning to admin
```

**Phone Number Validation:**
- Accept: +55 format or skip if not provided
- Extract: Only digits after country code
- Validate: Twilio/provider handles format validation
