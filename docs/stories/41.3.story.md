## Implementation Notes

- Follows RefundCalculator pattern (static class, reusable)
- Integrates with TierCalculator (loyalty_discount_percent parameter)
- Date calculations for accurate days_until_checkin
- Comprehensive error handling (validation before calculation)
- Portuguese language for guest-facing breakdown
- Decimal rounding for EUR cent accuracy
- Price floor protection prevents loss-making deals

## Discount Calculation Formula

```
Price Calculation Order:
1. Start with base_price
2. Subtract loyalty_discount_amount
3. Subtract last_minute_discount (if applicable)
4. Subtract extended_stay_discount (if applicable)
5. Subtract early_bird_discount (if applicable)
6. Add/subtract seasonal_adjustment
7. Apply price floor (minimum 50% of base)
```
