# Story 31.4 Manual QA Checklist

Goal: collect human evidence that branded booking confirmation emails render correctly in the main mail clients.

## Preconditions

- Use a real organization with branding configured.
- Ensure `RESEND_API_KEY` is set in the test environment.
- Send one test email from `src/app/api/organizations/[orgId]/email-templates/test/route.ts`.
- Use the same booking/template content for all clients.

## Gmail

- Open the test email in Gmail web.
- Confirm sender name and from-address match the organization.
- Confirm logo appears in the header when enabled.
- Confirm CTA button uses the organization primary color.
- Confirm unsubscribe link is visible and clickable.
- Confirm mobile view does not break layout.

## Outlook

- Open the test email in Outlook web or desktop.
- Confirm header, CTA, and footer render without clipping.
- Confirm template variables render as plain text.
- Confirm unsubscribe link remains visible.
- Confirm spacing and buttons remain readable.

## Apple Mail

- Open the test email in Apple Mail.
- Confirm MJML layout renders responsively.
- Confirm logo, CTA, and footer appear in the expected order.
- Confirm custom confirmation message is present.
- Confirm unsubscribe link is present and usable.

## Evidence to record

- Client tested.
- Date and time.
- Recipient address used.
- Screenshot or short note for each client.
- Any rendering issue observed.
