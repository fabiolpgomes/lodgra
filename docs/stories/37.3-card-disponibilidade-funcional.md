**Size:** 6h  
**Priority:** P1

---

## 📖 Story

Como proprietário, quero configurar regras de disponibilidade (mín/máx noites, aviso prévio, período de abertura) e ter validação automática ao fazer reservas.

---

## ✅ Acceptance Criteria

### Configuration
- [ ] AvailabilityCard carrega dados da API (`GET /api/properties/[id]/availability`)
- [ ] Proprietário pode editar:
  - Mínimo de noites (1-365)
  - Máximo de noites (1-365)
  - Aviso prévio (Mesmo dia, 1 dia, 2 dias, 7 dias)
  - Tempo de preparação (0, 1, 2, 7 dias)
  - Período de disponibilidade (24 meses, 12, 9, 6, 3 meses, ou "Datas indisponíveis por padrão")
- [ ] Opção: "Permitir pedidos com menos de 1 dia de aviso" (toggle)
  - Se ativado → modo "pendente para aprovação"
  - Se desativado → respeitam regra de aviso prévio
- [ ] Dados salvos via `PUT /api/properties/[id]/availability`

### Validation
- [ ] Impedir min > max noites
- [ ] Impedir período negativo
- [ ] Validar que min >= 1

### Reservation Blocking
- [ ] Quando hóspede tenta fazer reserva, validar:
  - Número de noites >= min_nights
  - Número de noites <= max_nights
  - Data check-in >= hoje + advance_notice_days (se não em modo aprovação)
  - Data check-out <= hoje + period_days
- [ ] Se validação falha → mostrar mensagem de erro ao hóspede
