## Acceptance Criteria

- [x] TierCalculator class implemented with tier mapping
  - Static method: `calculateTier(loyaltyScore: number): Tier`
  - Tier definitions by loyalty points:
    - Bronze: 0-25 pts → 0% discount
    - Silver: 26-50 pts → 5% discount
    - Gold: 51-75 pts → 10% discount
    - Platinum: 76-100 pts → 15% discount
  - Include `getNextTierInfo(currentScore): { next_tier, points_needed, discount_gain }`
  - Return: `{ tier_name, loyalty_score, base_discount_percent, perks }`

- [x] API Endpoint implemented (`src/app/api/guests/[id]/tier/route.ts`)
  - GET endpoint returning guest tier + discount info
  - Return: `{ guest_id, current_tier, loyalty_score, base_discount, next_tier, points_to_next }`
  - Include tier perks description

  - No new migrations needed
