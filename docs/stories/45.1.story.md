# Design System: Green to Emerald Color Migration

**Status:** Ready for Review  
**Epic:** 45 — Design System Alignment  
**Type:** Refactoring  
**Priority:** Medium  
**Complexity:** Medium (2-3 hours)

## Story

The design.md has been updated to use emerald (#00674F) as the success/growth color, replacing the previous green (#059669). However, the codebase still contains 341 references to Tailwind's `green-*` utilities. This story completes the implementation by migrating all color references from `green-*` to `emerald-*` (and shade-adjusted `emerald-*` where needed) to achieve design system consistency.

## Acceptance Criteria

- [ ] AC1: All `green-*` color references replaced with appropriate `emerald-*` shades (except demo pages)
- [ ] AC2: Demo pages (`src/app/demo/`) may retain `green-*` for development/testing purposes
- [ ] AC3: Color palette in design.md (`success: #00674F`, `success-light: #0A8B6F`) is the single source of truth
- [ ] AC4: No `#059669` or `rgb(5, 150, 105)` references remain in non-demo code
- [ ] AC5: Full test suite passes (2800+ tests) with zero regressions
- [ ] AC6: All pages render correctly in both light and dark modes
- [ ] AC7: Design system is now 100% aligned (45+ emerald references, 0 green-* references in production code)
