# Story 37.6: Drag-to-Select Visual Highlight

**Epic:** 37 — Calendar Pricing & Availability Management  
**Status:** Draft  
**Size:** 6h  
**Priority:** P1 (Blocks MVP completion)

---

## 📖 Story

Como proprietário, quero que quando seleciono dias no calendário em drag (arrastar), os dias selecionados fiquem destacados em azul para feedback visual claro durante a interação. Atualmente o drag funciona (modal abre com range correto) mas falta o feedback visual que torna a feature intuitiva.

---

## ✅ Acceptance Criteria

### Visual Feedback During Drag
- [ ] Quando user começa drag em dia X até dia Y, esses dias highlight em azul
- [ ] Highlight é visível em tempo real enquanto dragging
- [ ] Cor azul bem definida (usar tema design.md)

### Modal Behavior
- [ ] Highlight persiste enquanto modal está aberto (após drag)
- [ ] Highlight clears quando modal fecha
- [ ] Highlight clears quando user clica "Cancelar" ou clears selection

### Responsiveness
- [ ] Funciona perfeitamente em mobile (touch drag)
- [ ] Funciona perfeitamente em desktop (mouse drag)
- [ ] Sem lag com 30+ reservations no calendário

### Performance
- [ ] Sem re-renders desnecessários
- [ ] Transição suave (CSS transition or CSS-in-JS)
- [ ] Bundle size não aumenta

## 🔄 Dev Notes

### Current Implementation State
```typescript
// SimpleCalendarAdapter currently:
// - Detects drag start/end
// - Opens modal with correct range
// - Missing: visual highlight of selected days

// Solution approach:
// - Use useRef to track highlighted days (non-re-render)
// - CSS class applied: .day-highlighted
// - Clear highlight on modal close
```

### Recommended Architecture
```typescript
const highlightedDaysRef = useRef<Set<string>>(new Set());

function handleDragEnd(startDate, endDate) {
  // Populate ref with dates between start-end
  highlightedDaysRef.current = getDateRange(startDate, endDate);
  // Trigger render to apply CSS classes
  setHighlight(true); // minimal state for re-render
}

// In render:
// <CalendarDay highlighted={highlightedDaysRef.current.has(date)} />
```

### Styling Example
```css
.calendar-day {
  transition: background-color 0.2s ease;
}

.calendar-day.highlighted {
  background-color: #3B82F6; /* theme blue */
  color: white;
}
```

## 📞 Notes for @dev

1. **Current state:** Drag works functionally (modal opens, price calculates) but NO visual feedback
2. **Root cause:** selection.state doesn't propagate to visual layer (investigated 10+ sessions)
3. **Workaround:** Use useRef instead of useState for highlighting (avoids re-render issues)
4. **Timeline:** ~2-3 hours implementation, low risk (isolated to SimpleCalendarAdapter)
5. **Test thoroughly:** Mobile drag is different from desktop (touch vs mouse)
6. **No API changes needed** — this is pure UI/UX
