## 📖 Story

Como proprietário, quero oferecer descontos automáticos para clientes recorrentes (que já ficaram antes), e ter esses descontos aplicados automaticamente ao cálculo de preço e exibidos claramente ao hóspede durante a reserva.

---

## ✅ Acceptance Criteria

### Loyalty Discount Configuration
- [ ] Proprietário pode configurar desconto de fidelidade via DiscountCard (37.2)
  - Opção: "Hóspedes com excelentes avaliações" (4.8+ rating, mín 3 reviews)
  - Percentagem desconto (e.g., 10%)
- [ ] Desconto é **adicional** aos descontos de duração (semanal/mensal)

### Automatic Identification
- [ ] Sistema identifica cliente como "recorrente" se:
  - Tem histórico de ≥1 reserva anterior **confirmada**
  - Avaliação média >= 4.8 (ou sem avaliações, skip validation)
  - Mínimo 3 avaliações (ou skip validation)
- [ ] Consulta: `GET /api/guests/[guest_id]/loyalty-status`
  - Retorna: { is_loyal: boolean, average_rating: float, reservation_count: int }

### Pricing Calculation
- [ ] Quando calcula preço da nova reserva:
  - Aplicar descontos de duração (semanal/mensal) - 37.2
  - Se cliente é loyalty → aplicar desconto fidelidade **adicional**
  - Exemplo: €100/noite × 7 noites = €700
    - Desconto semanal -5% = €665
    - Desconto fidelidade -10% (adicional) = €598.50 ✅

### Display to Guest
- [ ] Durante seleção de datas/preço:
  - Mostrar breakdown de preço:
    - Preço base
    - Descontos de duração
    - "🎁 Desconto Fidelidade: -€66.50" (destacado em verde)
  - Ícone/badge "Cliente Fidelidade" perto de nome do hóspede
  - Mensagem: "Parabéns! Você ganhou um desconto de fidelidade por ser cliente recorrente!"

### Notification
- [ ] Email de confirmação de reserva menciona desconto fidelidade:
  - "Seu desconto de fidelidade de 10% foi aplicado"
  - "Economia total: €66.50"

## 🔄 Dev Notes

### Loyalty Identification
```typescript
async function checkLoyaltyStatus(guestId: string, propertyId: string) {
  const { data: guest } = await supabase
    .from('guests')
    .select('average_rating, reservation_count')
    .eq('id', guestId)
    .single();

  // Check if guest has previous confirmed reservations at this property
  const { data: prevReservations } = await supabase
    .from('reservations')
    .select('id')
    .eq('guest_id', guestId)
    .eq('property_id', propertyId)
    .eq('status', 'confirmed')
    .limit(1);

  return {
    is_loyal: 
      (guest?.average_rating >= 4.8 || !guest?.average_rating) &&
      (prevReservations?.length > 0),
    average_rating: guest?.average_rating || null,
    reservation_count: guest?.reservation_count || 0,
  };
}
```

### Pricing Flow
```typescript
// On price calculation:
const loyaltyStatus = await checkLoyaltyStatus(guest_id, property_id);
let finalPrice = basePrice;

// Apply duration discounts
if (nightCount >= 28) finalPrice *= (1 - monthlyDiscount);
else if (nightCount >= 7) finalPrice *= (1 - weeklyDiscount);

// Apply loyalty discount (if eligible)
if (loyaltyStatus.is_loyal && loyaltyDiscountConfig.enabled) {
  finalPrice *= (1 - loyaltyDiscountConfig.percentage);
}

return { finalPrice, breakdown: {...} };
```
