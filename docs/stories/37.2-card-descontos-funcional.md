# Story 37.2: Card Descontos (Funcional)

**Epic:** 37 — Calendar Pricing & Availability Management  
**Status:** Ready for Review  
**Size:** 6h  
**Priority:** P1

---

## 📖 Story

Como proprietário, quero configurar descontos por duração (semanal, mensal), descontos por avaliação de hóspede, e descontos por fidelidade, com cálculo automático aplicado às reservas.

---

## ✅ Acceptance Criteria

### Configuration
- [ ] DiscountCard carrega dados da API (`GET /api/properties/[id]/discounts`)
- [ ] Proprietário pode editar cada desconto via modal (semanal, mensal, fidelidade)
- [ ] Interface mostra:
  - Semanal: Para 7+ noites, percentagem desconto, média semanal (€894)
  - Mensal: Para 28+ noites, percentagem desconto, média mensal (€1.724)
  - Fidelidade: Para clientes com excelentes avaliações (4.8+), percentagem desconto adicional
- [ ] Todos os valores salvos via `PUT /api/properties/[id]/discounts/[discountId]`

### Calculation
- [ ] Descontos são aplicados em cascata: semanal OU mensal (não ambos)
- [ ] Se fidelidade ativada E cliente é recorrente → desconto fidelidade é adicional
- [ ] Cálculo exemplo: €100/noite × 7 noites = €700 → desconto semanal -5% = €665
- [ ] Validação: percentagem 0-100%

### Data Persistence
- [ ] Valores persistem após reload
- [ ] Histórico de mudanças em `updated_at`
