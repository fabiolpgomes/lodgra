# Story 43.6: Advanced Analytics with Delivery Webhooks

**Depends On:**
- ✅ Story 43.3 (Email Confirmation)
- ✅ Story 43.4 (SMS Notifications)
- ✅ Story 43.5 (Email & SMS Analytics)

---

## Story

As an **admin monitoring direct bookings**, I need to **track email and SMS delivery status via provider webhooks** — so I can see real-time delivery confirmations and detect failed messages automatically.

---

## Acceptance Criteria

- [ ] **SendGrid Webhook Handler** — Receive delivery events from SendGrid
  - Route: POST `/api/webhooks/sendgrid`
  - Parse: message_id, status (delivered/bounce/dropped), timestamp
  - Update: notification_logs table with final status
  - Verify: Webhook signature for security

- [ ] **Twilio Webhook Handler** — Receive delivery events from Twilio
  - Route: POST `/api/webhooks/twilio`
  - Parse: MessageSid, MessageStatus (delivered/failed), timestamp
  - Update: notification_logs table with final status
  - Verify: Webhook signature for security

- [ ] **Delivery Status Dashboard** — Show real-time delivery metrics
  - Chart: Delivery timeline (sent → delivered/failed)
  - Metrics: % delivered, % bounced, % failed, avg delivery time
  - Alerts: Red alert if failure rate > 5% in last 24h
  - Export: CSV/JSON report of delivery events

- [ ] **Failure Notifications** — Alert on delivery issues
  - Alert: If email bounces/fails
  - Alert: If SMS delivery fails
  - Admin email: Summary of daily failures (cron job)
  - UI: Red badge on analytics page if issues detected

- [ ] **Unit Tests** — Webhook logic
  - Test webhook signature verification
  - Test status update logic
  - Test error handling
  - Test idempotency (duplicate webhooks)

## Dev Notes

**Webhook Event Types:**

**SendGrid:**
```json
{
  "message_id": "...",
  "event": "delivered|bounce|dropped|spamreport|unsubscribe",
  "timestamp": 1626567890,
  "email": "guest@email.com"
}
```

**Twilio:**
```json
{
  "MessageSid": "SMxxxxxxx",
  "MessageStatus": "delivered|failed|undelivered",
  "Timestamp": "2026-07-31T10:00:00Z",
  "To": "+5511987654321"
}
```

**Signature Verification:**
- SendGrid: HMAC-SHA256(webhook_signing_secret, payload)
- Twilio: Uses auth token for verification

**Status Mapping:**
- SendGrid → notification_logs: delivered/failed/bounced
- Twilio → notification_logs: delivered/failed
