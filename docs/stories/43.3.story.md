# Story 43.3: Email Confirmation for Direct Bookings

**Depends On:**
- ✅ Story 43.2 (Direct Booking Creation page)
- ✅ Story 43.1 (Reservation Validator)

---

## Story

As an **admin creating a direct booking**, I need to **send a confirmation email to the guest** — so they receive booking details and can review their reservation immediately.

---

## Acceptance Criteria

- [ ] **Email Confirmation Trigger** — Send email after successful reservation creation
  - Trigger: POST /api/admin/reservations returns success
  - Send to: guestEmail from reservation
  - Timing: Immediate (sync or async task)
  - Success: Email queued/sent without blocking API response

- [ ] **Email Template** — Professional confirmation email
  - Subject: "Confirmação de Reserva - Lodgra"
  - Content includes:
    - Guest name
    - Property name/address
    - Check-in date + check-out date
    - Number of nights
    - Guest count
    - Final price (currency formatted)
    - Cancellation policy summary
    - Support contact info
  - Format: Plain text + HTML template
  - Branding: Lodgra logo/colors

- [ ] **Email Service Integration** — Use SendGrid or similar
  - API key from environment variables
  - Error handling: Log failures without crashing reservation creation
  - Retry logic: Attempt 2-3 times if initial send fails
  - Rate limiting: Respect SendGrid limits

- [ ] **Email Logging** — Track sent emails
  - Store in `emails_sent` table (optional)
  - Fields: reservation_id, guest_email, sent_at, status, error_message
  - Enable admin to resend emails if needed

- [ ] **Unit Tests** — Email sending logic
  - Test successful email send
  - Test email with special characters in guest name
  - Test error handling (email service down)
  - Test retry logic
  - Test missing environment variables

## Dev Notes

**Email Service Options:**
1. **SendGrid** (recommended)
   - $0.10 per email or free tier (12K/month)
   - Reliable, good deliverability
   - Environment variable: `SENDGRID_API_KEY`

2. **Resend** (alternative)
   - $0.20 per email or free tier
   - Lightweight, TypeScript-friendly
   - Environment variable: `RESEND_API_KEY`

3. **Nodemailer** (local SMTP)
   - No cost, self-hosted
   - Requires SMTP server
   - Less reliable for production

**Recommendation:** SendGrid (most stable, good pricing)

**Email Template Variables:**
```
{guestName}
{propertyName}
{propertyAddress}
{checkInDate} (format: DD/MM/YYYY)
{checkOutDate}
{nights}
{guestCount}
{finalPrice} (format: €XXX.XX)
{cancellationPolicyName}
{refundPercentage}
{refundDeadlineDays}
{supportEmail}
{supportPhone}
```

**Error Handling Strategy:**
```
try:
  send_email()
catch:
  log error to database
  attempt retry (max 2)
  if all attempts fail:
    - send warning to admin
    - return success anyway (don't block reservation)
```
