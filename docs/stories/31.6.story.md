# Story 31.6: Analytics Dashboard (Traffic by Company)

**Epic:** Epic 31 — Multi-Tenant Infrastructure (Branded Direct Booking)  
**Status:** Ready for Review  
**Priority:** High  
**Type:** Backend + Dashboard  
**Assigned to:** @dev

## Story

**As** a Lodgra customer,  
**I want** to see traffic for my branded booking pages,  
**So that** I can understand how my company link is being used.

## Context

Story 31.6 extends the branded direct-booking experience with a lightweight analytics layer that records consent-aware page views for company booking pages and public property pages. The goal is to surface simple, actionable traffic data inside the app without depending on a separate external reporting pipeline.

## Acceptance Criteria

- [x] AC1: Page views from branded company pages are recorded when analytics consent is accepted.
- [x] AC2: Traffic events are associated with the tenant organization and captured by company slug.
- [x] AC3: Settings analytics page shows traffic summary for the current organization.
- [x] AC4: Dashboard includes total views, 7-day views, top paths, hostnames, and last activity.
- [x] AC5: Public pages do not track when analytics consent is declined.
- [x] AC6: No regression in the existing Google Analytics settings flow.

## Tasks

- [x] Add consent-aware traffic event capture for public company pages.
- [x] Add storage and ingestion for organization traffic events.
- [x] Add analytics summary dashboard to organization settings.
- [x] Add tests for the traffic summary helper and ingestion endpoint.
- [x] Run quality gates.

## Dev Notes

- Traffic capture is limited to company subdomains and public property pages.
- The tracker waits for `cookie_consent_analytics` before sending events.
- Dashboard data is aggregated from `organization_traffic_events`.
