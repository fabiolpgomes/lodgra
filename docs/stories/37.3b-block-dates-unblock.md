# Story 37.3B: Desbloquear Datas (Block Dates Unblock)

**Epic:** 37 — Calendar Pricing & Availability Management  
**Status:** Ready for Review  
**Size:** 2h  
**Priority:** P1

---

## 📖 Story

Como proprietário, quero desbloquear datas que foram previamente bloqueadas, para que possa torná-las disponíveis para reservas novamente quando as circunstâncias mudarem.

---

## ✅ Acceptance Criteria

### DELETE Endpoint
- [x] Endpoint `DELETE /api/properties/[id]/calendar/blocked-dates/[blockId]` criado
- [x] Verifica autenticação (user logged in)
- [x] Verifica ownership (organization_id match)
- [x] Verifica block existence
- [x] Retorna 401 se não autenticado
- [x] Retorna 403 se org não corresponde
- [x] Retorna 404 se block não encontrado
- [x] Retorna 200 com sucesso
- [x] Log para auditoria

### Unblock UI
- [x] Ao clicar em data bloqueada (🔒), modal mostra opção de desbloquear
- [x] Modal exibe motivo do bloqueio (do field `notes`)
- [x] Botão "Desbloquear Datas" disponível
- [x] Loading state durante operação
- [x] Toast de sucesso ao desbloquear
- [x] Toast de erro se falhar
- [x] Calendário atualiza após desbloquear (🔒 desaparece)
- [x] Data fica disponível para novas reservas

### Validation
- [x] Não permite desbloquear blocos de outra organização
- [x] Valida que blockId pertence à property
- [x] Mensagens de erro descritivas
