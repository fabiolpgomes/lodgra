## Story

As an **admin managing direct bookings**, I need to **track email and SMS delivery metrics** — so I can monitor notification effectiveness and identify delivery issues.

## Dev Notes

**Database Schema:**
```sql
CREATE TABLE notification_logs (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  type VARCHAR(10) NOT NULL, -- 'email' or 'sms'
  reservation_id UUID NOT NULL REFERENCES reservations(id),
  guest_email VARCHAR(255),
  guest_phone VARCHAR(20),
  status VARCHAR(20) NOT NULL, -- 'sent', 'failed', 'pending'
  message_id VARCHAR(100), -- Provider message ID (SendGrid SID, Twilio SID)
  error_message TEXT,
  sent_at TIMESTAMP NOT NULL DEFAULT NOW(),
  created_at TIMESTAMP NOT NULL DEFAULT NOW(),
  FOREIGN KEY (reservation_id) REFERENCES reservations(id)
);

CREATE INDEX idx_notification_logs_reservation_id ON notification_logs(reservation_id);
CREATE INDEX idx_notification_logs_type ON notification_logs(type);
CREATE INDEX idx_notification_logs_status ON notification_logs(status);
CREATE INDEX idx_notification_logs_sent_at ON notification_logs(sent_at);
```

**Analytics Calculations:**
```
Total Sent = COUNT(*) WHERE type = 'email' OR 'sms'
Success Count = COUNT(*) WHERE status = 'sent'
Success Rate = (Success Count / Total Sent) * 100
Failed Count = COUNT(*) WHERE status = 'failed'
Average Send Time = AVG(sent_at - created_at)
```

**Resend Flow:**
1. User clicks "Resend" on failed notification
2. Check reservation + guest details
3. Call sendReservationConfirmationEmailWithRetry() or sendReservationSMSWithRetry()
4. Log new attempt to notification_logs
5. Return status to UI
